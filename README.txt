RACHELLE - SALÓN DE BELLEZA
Versión profesional estática

Archivos principales:
- index.html  -> estructura de la página
- style.css   -> diseño, colores, tamaños y responsive
- script.js   -> menú móvil, animaciones, filtros de galería y lightbox
- images/     -> logo e imágenes de prueba

Cómo abrir la página:
1. Abre la carpeta rachelle-web.
2. Haz doble clic en index.html.
3. La página se abrirá en tu navegador.

Cómo cambiar el logo:
1. Guarda tu logo dentro de images/.
2. Usa el nombre logo-rachelle.png.
3. Si usas otro nombre, cambia esta línea en index.html:
   <img src="images/logo-rachelle.png" alt="Logo Rachelle" class="brand-logo" />

Cómo cambiar imágenes:
1. Mete tus fotos en la carpeta images/.
2. Usa nombres sin espacios ni acentos, por ejemplo:
   unas-acrilicas.jpg
   tinte-rubio.jpg
   pestanas-pelo-a-pelo.jpg
3. En index.html cambia el src de cada imagen, por ejemplo:
   <img src="images/unas-acrilicas.jpg" alt="Uñas acrílicas" />

Cómo agregar Instagram después:
Por ahora Instagram queda pendiente para no mostrar un botón sin enlace real.
Cuando tengas el enlace, se puede agregar un botón en la sección CONTACTO.

Cómo cambiar ubicación:
Busca la sección UBICACIÓN en index.html.
Ahí puedes cambiar dirección y horario.
Después se puede reemplazar el bloque del mapa por un iframe real de Google Maps.

Sobre esta versión:
- Es una página estática.
- No usa base de datos.
- No tiene precios visibles.
- No tiene sistema para que clientes suban contenido.
- Está pensada para que las clientas escriban por WhatsApp.
- Incluye diseño responsive para celular, tablet y computadora.
